# Фронтенд (этап 0б)

Без сборки: обычные файлы HTML/CSS/JS. Адрес API уже прописан в `config.js`.

## Проверка на компьютере
В VS Code установи расширение **Live Server**, открой папку `web`, нажми «Go Live». Либо в терминале внутри `web`: `python -m http.server 8080` и открой http://localhost:8080.
Нужен именно адрес localhost или https: service worker и установка PWA на `file://` не работают.

## Публикация (бесплатно)
Загрузи содержимое папки `web` на GitHub Pages или Cloudflare Pages. Адрес должен быть https.

## Установка на iPhone
Открой сайт в Safari → «Поделиться» → «На экран “Домой”».

## Что внутри
- `index.html`, `styles.css`, `app.js`: вход, регистрация, главный экран-заготовка, смена пароля.
- `sw.js`: кэширует только свои файлы, запросы к API не кэшируются.
- Токен сессии хранится в `localStorage`; в страницу включена строгая политика CSP (скрипты только свои).
